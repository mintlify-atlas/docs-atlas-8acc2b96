Shape Your Life ID uses [Spatie Laravel Permission](https://spatie.be/docs/laravel-permission) to manage role-based access control. Each admin user is assigned one or more roles, and each role holds a set of permissions that control which sections of the admin panel they can access. Roles and permissions are stored in the database using UUID primary keys and are cached for performance.

## Understanding roles

A role is a named group that bundles one or more permissions together. You assign a role to a user rather than assigning individual permissions directly to them. This makes it easy to manage access at scale — update a role once and every user with that role immediately inherits the change.

Roles are managed at `/admin/role`. From this page you can:

- **List** all existing roles in a DataTable view
- **Create** a new role by providing a unique name
- **Edit** an existing role's name
- **Delete** a role (users who held the role will lose its permissions)
- **Assign permissions** to a role via the role detail page

Access to the Roles page requires the `roles` permission.

## Assigning permissions to a role

<Steps>
  <Step title="Open the Roles page">
    Navigate to **User Access → Roles** in the sidebar. You must have the `roles` permission to access this page.
  </Step>
  <Step title="Open the role detail">
    Click the role you want to configure. The detail page lists all available permissions in the system.
  </Step>
  <Step title="Select permissions">
    Check the permissions you want to grant to the role. Uncheck any permissions you want to revoke.
  </Step>
  <Step title="Save">
    Click **Assign Permission**. The changes take effect immediately and are reflected for all users who hold that role.
  </Step>
</Steps>

<Warning>
  Removing a permission from a role immediately restricts access for every user assigned to that role. Those users will no longer see the corresponding menu item and will receive an authorisation error if they try to access the URL directly.
</Warning>

## Assigning roles to users

<Steps>
  <Step title="Open the Users page">
    Navigate to **User Access → Users** in the sidebar. You must have the `user-admins` permission.
  </Step>
  <Step title="Edit the user">
    Click **Edit** on the user you want to update.
  </Step>
  <Step title="Select a role">
    In the edit form, choose the desired role from the **Role** dropdown. Only non-member roles (that is, roles other than `head`, `co-head`, and `member`) are available here.
  </Step>
  <Step title="Save">
    Submit the form. The user's permissions are updated immediately based on the new role assignment.
  </Step>
</Steps>
