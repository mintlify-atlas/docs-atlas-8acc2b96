This guide walks you through cloning the repository, installing dependencies, configuring your environment, and running the application locally for the first time. By the end, you will have a fully seeded local instance with a working admin account.

<Note>
  Shape Your Life ID requires **PHP 8.1 or higher**. Make sure you also have the following PHP extensions enabled: `pdo`, `pdo_mysql`, `mbstring`, `openssl`, `tokenizer`, `xml`, `ctype`, `json`, `bcmath`, and `fileinfo`. These are standard on most PHP installations. You also need **Node.js 18+**, **Composer**, and a running **MySQL** database.
</Note>

## Installation

<Steps>
  <Step title="Clone the repository">
    Download the source code from GitHub:

    ```bash
    git clone https://github.com/shapeyourlifeid-org/shapeyourlifeid.git
    cd shapeyourlifeid
    ```
  </Step>

  <Step title="Install PHP dependencies">
    Install all Composer packages, including Laravel 10, Spatie Laravel Permission, and other backend dependencies:

    ```bash
    composer install
    ```
  </Step>

  <Step title="Install JavaScript dependencies">
    Install the frontend build dependencies including Vite, Tailwind CSS, and Alpine.js:

    ```bash
    npm install
    ```
  </Step>

  <Step title="Copy the environment file">
    Create your local `.env` file from the example template:

    ```bash
    cp .env.example .env
    ```

    Then open `.env` and update the following values at minimum:

    ```bash
    APP_NAME="Shape Your Life ID"
    APP_URL=http://localhost:8000

    DB_HOST=127.0.0.1
    DB_PORT=3306
    DB_DATABASE=shapeyourlifeid
    DB_USERNAME=your_db_user
    DB_PASSWORD=your_db_password
    ```

    If you plan to use Cockpit CMS for dynamic content, also set:

    ```bash
    API_COCKPIT_URL=https://your-cockpit-instance.com/api/
    KEY_COCKPIT=your_cockpit_api_key
    ```
  </Step>

  <Step title="Generate the application key">
    Generate a unique encryption key for the application:

    ```bash
    php artisan key:generate
    ```
  </Step>

  <Step title="Run database migrations">
    Create all the required tables in your database:

    ```bash
    php artisan migrate
    ```
  </Step>

  <Step title="Seed the database">
    Populate the database with roles, permissions, default users, and master data (countries, funding types, degree levels, scholarship categories, divisions, and teams):

    ```bash
    php artisan db:seed
    ```
  </Step>

  <Step title="Build frontend assets">
    Compile Tailwind CSS and other frontend assets for the first time:

    ```bash
    npm run build
    ```
  </Step>

  <Step title="Start the development server">
    Launch the Laravel development server:

    ```bash
    php artisan serve
    ```

    The application is now available at [http://localhost:8000](http://localhost:8000).
  </Step>
</Steps>

## Default admin accounts

After running `php artisan db:seed`, two accounts are created by `UserSeeder`:

| Name | Email | Password | Role |
|---|---|---|---|
| Super Admin | `superadmin@gmail.com` | `123123123` | `super-admin` |
| Developer Handal | `dev.admin@gmail.com` | `123123123` | `developer` |

Log in at `/admin` using either account. Change these credentials immediately in any environment other than a fresh local setup.
